# جيني برو | النظام المالي للمشاوير

تطبيق ويب شخصي (ملف واحد) يساعدك على تسجيل مشاويرك من صور شاشة تطبيق التوصيل، وحساب الربح الصافي بعد خصم бенزين، ومتابعة عداد السيارة وتعبئة الوقود، والحصول على توصيات ذكية.

التطبيق **عام للجميع**—لا يحتوي على أسماء مدن أو أنواع سيارات محددة. سجل المشاوير الخاص بك يُحفظ في متصفحك فقط ولا يُشارك مع أحد.

## ما الذي يفعله التطبيق

| الميزة | شرح |
|--------|-----|
| 📸 قراءة الصور | raised صور شاشة المشاوير،(app) يستخرج الوقت والربح والمسافة والمدة والتاريخ تلقائياً |
| 🔢 دعم الأرقام العربية | يقرأ `٣,٩` (= 3.9 كم)، `٦.٥٧` (= 6.57 ريال)، `١٠` (= 10 دقائق)، `٧:٥٣ م` (= 07:53 م) |
| 📋 مشاوير متعددة | إذا كانت الصورة فيها مشوار واحد يسجل واحدًا، وإذا فيها أكثر من مشوار يسجلهم جميعاً "حبه حبه" |
| 📅 تاريخ تلقائي | يضبط تاريخ اليوم حسب توقيت السعودية (الرياض) ويوم الأسبوع (جمعة، سبت، إلخ) لوحده |

| 📊 مؤشرات ذكية | إجمالي الربح، الصافي بعد البنزين، الربح بالساعة، أفضل يوم، تغطية الهدف الشهري |
| 📟 عداد السيارة | احسب المسافة الفارغة وتكلفة البنزين الفعلية من عداد الطبلون |

| 🧠 مستشار ذكي | تحليل أفضل الأوقات، تقييم اليوم، خطة للوصول إلى 100 ريال يومياً |
| ⚡ فحص عرض | احسب إذا كان العرض المُعرض عليك ربحياً أم لا قبل القبول |
| 🔐 نسخ احتياطي | تصدير واستيراد جميع بياناتك كملف JSON |

## الملفات الموجودة في المشروع

| الملف | الوظيفة |
|------|---------|
| `index.html` | التطبيق كامل (الواجهة + كل منطق القراءة والحفظ). هذا هو الملف الأساسي الذي تشغّله. |
| `manifest.json` | إعدادات التطبيق ليُثبّت على الجوال كتطبيق عادي (PWA). |
| `sw.js` | ملف Service Worker لتشغيل التطبيق بدون إنترنت وفتحه بسرعة. |
| `icon.svg` | أيقونة التطبيق التي تظهر على شاشة الجوال الرئيسية. |
| `LICENSE` | رخصة الاستخدام (MIT). |
| `.gitignore` | ملف يخبر الجيت هاب بأي ملفات ومجلدات لا يجب رفعها (مثل السجلات والملفات المؤقتة). |
| `README.md` | هذا الملف (شرح كامل للتطبيق وكيفية رفعه). |

## كيف تشغّل التطبيق على جهازك

### أسهل طريقة (بدون أي إعداد)
افتح ملف `index.html` مباشرة بأي متصفح على الجوال أو الكمبيوتر. يعمل فوراً، وكل بياناتك تُحفظ في متصفحك فقط.

### דרך تشغّله عبر سيرفر محلي (للمطورين)
داخل مجلد المشروع شغّل:

```bash
python3 -m http.server 8000
```

ثم افتح من المتصفح:

```
http://localhost:8000
```

## كيف ترفع الملفات على GitHub (طريقة السحب والإفلات - الأسهل)

### 1. أنشئ حساب على GitHub
اذهب إلى https://github.com وأنشئ حساباً مجانياً إذا لم يكن لديك حساب.

### 2. أنشئ مستودعاً جديداً (Repository)
1. بعد تسجيل الدخول، اضغط على علامة `+` أعلى الصفحة ثم اختر **New repository**.
2. اسم المستودع: `jeeny-pro` (أو أي اسم تريده).
3. اختر **Public** (يجب أن يكون عام لكي تعمل الاستضافة المجانية عبر GitHub Pages).
4. **لا تضف** README ولا .gitignore ولا أي ملف آخر، لأن لديك ملفاتك الخاصة.
5. اضغط **Create repository**.

### 3. ارفع الملفات (Upload)
1. داخل صفحة المستودع الجديدة، اضغط على الرابط `uploading an existing file` أو زر **Add file** ثم **Upload files**.
2. اسحب كل ملفات هذا المجلد إلى الصفحة:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icon.svg`
   - `LICENSE`
   - `.gitignore`
   - `README.md`
3. اكتب تعليقاً بسيطاً أسفل الصفحة مثلاً: "Initial commit - Jeeny Pro app".
4. اضغط **Commit changes**.

### 4. فعّل الاستضافة المجانية (GitHub Pages)
1. من صفحة المستودع، اضغط على تبويب **Settings**.
2. من القائمة اليسارية اضغط على **Pages**.
3. تحت قسم **Build and deployment**:
   - **Source**: اختر "Deploy from a branch".
   - **Branch**: اختر `main` والمجلد `/ (root)`.
   - اضغط **Save**.
4. انتظر حوالي دقيقة إلى دقيقتين، سيظهر رابط موقعك على شكل:
   ```
   https://اسم-المستخدم-خاص-بك.github.io/jeeny-pro/
   ```
5. افتح الرابط من جوالك، التطبيق شغال ومجاني للأبد.

**هل يكفي GitHub كاستضافة؟**
نعم. GitHub Pages هو استضافة مجانية كاملة للمواقع الثابتة مثل هذا التطبيق. لا تحتاج لدفع أي مبلغ، والموقع يظل شغالاً مدى الحياة طالما المستودع موجود.

## كيف تثبت التطبيق على الشاشة الرئيسية للجوال

هذا التطبيق هو **PWA** (تطبيق ويب تقدمي)، يمكن إضافته للشاشة الرئيسية ويفتح بدون شريط المتصفح، ويعمل بدون إنترنت.

### لأندرويد (كروم)
1. افتح رابط الموقع في متصفح Chrome على جوالك.
2. اضغط على قائمة النقاط الثلاث (⋮) أعلى الشاشة.
3. اختر **"إضافة إلى الشاشة الرئيسية"** أو **"تثبيت التطبيق"**.
4. سيظهر الأيقونة باسم "جيني برو" على شاشتك الرئيسية.

### لآيفون (سفاري)
1. افتح رابط الموقع في سفاري.
2. اضغط على زر المشاركة (مربع مع سهم إلى أعلى).
3. اسحب لأسفل واختر **"إضافة إلى الشاشة الرئيسية"**.
4. سمّه "جيني برو" واضغط إضافة.

## أين تُخزّن البيانات؟ (مهم جداً)

كل بياناتك (المشاوير، العداد، البنزين) تُخزّن داخل **متصفح جوالك فقط** (localStorage).
- التطبيق لا يرفع بياناتك لأي سيرفر خارجي.
- إذا مسحت بيانات المتصفح أو غيرت الجهاز، البيانات ستختفي.
- لذلك من المهم جداً ضغط **"تصدير كل بياناتي"** في تبويب الإعدادات بشكل دوري، والاحتفاظ بالملف `jeeny_full_backup.json` الذي يتم تنزيله.
- لاستعادة البيانات على جهاز آخر: افتح التطبيق، اذهب إلى الإعدادات، اضغط **"استيراد بياناتي"** واختر الملف.

## ملف `.gitignore` — هل أرفعه أم لا؟

**نعم، ارفعه إلى GitHub.**

` .gitignore ` هو ملف نصي بسيط يخبر برنامج Git بأي ملفات ومجلدات لا يجب أن تتبعها أو ترفعها للمستودع (مثل `node_modules/`, `*.log`, `.env`).

- إذا رفعته إلى GitHub: سيظل سارياً على المستودع، ولن يتم تتبع الملفات التيstruكwriteها بداخله حتى لو كانت موجودة على جهازك.
- إذا لم ترفعه: كل من يClone المستودع لن يعرف أي ملفات يجب تجاهلها.

المحتوى الحالي في `.gitignore` يمنع رفع الملفات المؤقتة والسجلات، وهذا أمر طبيعي ومُستحسن. **ارفعه مع بقية الملفات.**

## مثال على الصورة المطلوب قراءتها

لصورتك، المفترض أن يقرأ التطبيق هذه القيم بدقة:

| الحقل | القيمة |
|-------|--------|
| الوقت | 7:53 م |
| ربح التطبيق (ريال) | 6.57 |
| المسافة (كم) | 3.9 |
| المدة (دقائق) | 10 |

إذا رفعت صورة فيها مشوار واحد، يسجل مشوار واحد. إذا رفعت صورة فيها أكثر من مشوار، يسجلهم جميعاً كل مشوار على حدة مع وقته وربحه ومسافته ومدته، والتاريخ يُحدد تلقائياً من التاريخ الميلادي ويوم الأسبوع يُحسب لوحده (مثال: الجمعة 15 أكتوبر 2026).

## مفتاح Gemini API (اختياري)

التطبيق يقرأ الصور باستخدام محرك محلي (Tesseract) وبدون إنترنت، ويعمل بشكل جيد مع الصور الواضحة.

إذا أردت دقة أعلى في القراءة، يمكنك الحصول على مفتاح مجاني من [Google AI Studio](https://aistudio.google.com/apikey) ووضعه في تبويب "الإعدادات" في التطبيق. هذا الخيار **اختياري تماماً**، التطبيق يعمل بدونه. المفتاح يُخزّن في متصفحك فقط ولا يُرسل إلا لجوجل.
