# جيني برو | النظام المالي للمشاوير

تطبيق ويب شخصي (ملف واحد) يساعدك على تسجيل مشاويرك من صور شاشة تطبيق التوصيل، وحساب الربح الصافي بعد خصم البنزين والمصاريف، ومتابعة عداد السيارة وتعبئة الوقود، وتحليل أرباحك برسوم بيانية، والحصول على توصيات ذكية.

التطبيق **عام للجميع** — لا يحتوي على أسماء مدن أو أنواع سيارات محددة. سجل المشاوير الخاص بك يُحفظ في متصفحك فقط ولا يُشارك مع أحد.

| الميزة | شرح |

| 🔢 دعم الأرقام العربية | يقرأ `٣,٩` (= 3.9 كم)، `٦.٥٧` (= 6.57 ريال)، `١٠` (= 10 دقائق)، `٧:٥٣ م` (= 07:53 م) |

| 🧾 سجل المصاريف | سجّل الزيت والصيانة والتأمين وغيرها لتُخصم من ربحك الصافي الحقيقي |

| ⛽ تعبئة البنزين | سجّل مبالغ التعبئة في المحطة لمعرفة إجمالي ما دفعته |
| 🧠 مستشار ذكي | تحليل أفضل الأوقات، تقييم اليوم، خطة للوصول إلى هدفك اليومي |
| ⚡ فحص عرض | احسب إذا كان العرض المعروض عليك ربحياً أم لا قبل القبول |
| 🔔 تنبيهات | تذكير بتسجيل مشاوير اليوم، وتذكير دوري بأخذ نسخة احتياطية |
| 🔐 نسخ احتياطي | تصدير واستيراد جميع بياناتك (بما فيها الإعدادات والمصاريف) كملف JSON |

## الملفات الموجودة في المشروع

| الملف | الوظيفة |
|------|---------|
| `index.html` | التطبيق كامل (الواجهة + كل منطق القراءة والحفظ). هذا هو الملف الأساسي. |
| `manifest.json` | إعدادات التطبيق ليُثبَّت على الجوال كتطبيق عادي (PWA). |
| `sw.js` | ملف Service Worker لتشغيل التطبيق بدون إنترنت وفتحه بسرعة. |
| `icon.svg` | أيقونة التطبيق الأصلية (متجهية). |
| `icon-192.png` / `icon-512.png` | أيقونات جاهزة بأحجام قياسية لأندرويد و كروم. |
| `apple-touch-icon.png` | أيقونة خاصة بآيفون (سفاري) بحجم 180×180. |
| `LICENSE` | رخصة الاستخدام (MIT). |
| `.gitignore` | ملف يخبر Git بأي ملفات ومجلدات لا يجب رفعها (مثل السجلات والملفات المؤقتة). |
| `README.md` | هذا الملف. |

## كيف تشغّل التطبيق على جهازك

### أسهل طريقة (بدون أي إعداد)
افتح ملف `index.html` مباشرة بأي متصفح على الجوال أو الكمبيوتر. يعمل فوراً، وكل بياناتك تُحفظ في متصفحك فقط.

### تشغيله عبر سيرفر محلي (للمطورين)
```bash
python3 -m http.server 8000
```
ثم افتح من المتصفح: `http://localhost:8000`

## كيف ترفع الملفات على GitHub (طريقة السحب والإفلات)

### 1. أنشئ حساباً على GitHub
اذهب إلى https://github.com وأنشئ حساباً مجانياً إذا لم يكن لديك حساب.

### 2. أنشئ مستودعاً جديداً (Repository)
1. بعد تسجيل الدخول، اضغط على علامة `+` أعلى الصفحة ثم اختر **New repository**.
2. اسم المستودع: `jeeny-pro` (أو أي اسم تريده).
3. اختر **Public** (يجب أن يكون عاماً لكي تعمل الاستضافة المجانية عبر GitHub Pages).
4. **لا تضف** README ولا `.gitignore` ولا أي ملف آخر، لأن لديك ملفاتك الخاصة.
5. اضغط **Create repository**.

### 3. ارفع الملفات (Upload)
1. داخل صفحة المستودع، اضغط **Add file** ثم **Upload files**.
2. اسحب كل ملفات هذا المجلد إلى الصفحة:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icon.svg`
   - `icon-192.png`
   - `icon-512.png`
   - `apple-touch-icon.png`
   - `LICENSE`
   - `.gitignore`
   - `README.md`
3. اكتب تعليقاً بسيطاً أسفل الصفحة مثلاً: `Initial commit - Jeeny Pro app`.
4. اضغط **Commit changes**.

### 4. فعّل الاستضافة المجانية (GitHub Pages)
1. من صفحة المستودع، اضغط على تبويب **Settings**.
2. من القائمة الجانبية اضغط على **Pages**.
3. تحت قسم **Build and deployment**:
   - **Source**: اختر "Deploy from a branch".
   - **Branch**: اختر `main` والمجلد `/ (root)`.
   - اضغط **Save**.
4. انتظر دقيقة إلى دقيقتين، سيظهر رابط موقعك بالشكل:
   ```
   https://اسم-المستخدم.github.io/jeeny-pro/
   ```
5. افتح الرابط من جوالك، التطبيق شغال ومجاني للأبد.

**هل يكفي GitHub كاستضافة؟**
نعم. GitHub Pages استضافة مجانية كاملة للمواقع الثابتة مثل هذا التطبيق.

## كيف تثبت التطبيق على الشاشة الرئيسية للجوال

هذا التطبيق هو **PWA** (تطبيق ويب تقدمي)، يمكن إضافته للشاشة الرئيسية ويفتح بدون شريط المتصفح، ويعمل بدون إنترنت.

### لأندرويد (كروم)
1. افتح رابط الموقع في متصفح Chrome.
2. اضغط على قائمة النقاط الثلاث (⋮) أعلى الشاشة.
3. اختر **"إضافة إلى الشاشة الرئيسية"** أو **"تثبيت التطبيق"**.
4. ستظهر الأيقونة باسم "جيني برو" على شاشتك الرئيسية.

### لآيفون (سفاري)
1. افتح رابط الموقع في سفاري.
2. اضغط على زر المشاركة (مربع مع سهم إلى أعلى).
3. اسحب لأسفل واختر **"إضافة إلى الشاشة الرئيسية"**.
4. سمّه "جيني برو" واضغط إضافة.

## أين تُخزَّن البيانات؟ (مهم جداً)

كل بياناتك (المشاوير، العداد، البنزين، المصاريف، الإعدادات) تُخزَّن داخل **متصفح جوالك فقط** (localStorage).
- التطبيق لا يرفع بياناتك لأي سيرفر خارجي.
- إذا مسحت بيانات المتصفح أو غيّرت الجهاز، البيانات ستختفي.
- لذلك من المهم جداً الضغط على **"تصدير كل بياناتي"** في تبويب الإعدادات بشكل دوري (مرة كل أسبوع)، والاحتفاظ بالملف الذي يتم تنزيله.
- التطبيق يُظهر لك **تنبيهاً** إذا مرّ أكثر من أسبوع على آخر نسخة احتياطية.
- لاستعادة البيانات على جهاز آخر: افتح التطبيق، اذهب إلى الإعدادات، اضغط **"استيراد بياناتي"** واختر الملف.

## ملف `.gitignore` — هل أرفعه أم لا؟

**نعم، ارفعه إلى GitHub.**

`.gitignore` ملف نصي بسيط يخبر برنامج Git بأي ملفات ومجلدات لا يجب تتبعها أو رفعها للمستودع (مثل `node_modules/`, `*.log`, `.env`).

- إذا رفعته إلى GitHub: سيظل سارياً على المستودع، ولن يتم تتبع الملفات المذكورة بداخله.
- إذا لم ترفعه: كل من ينسخ (Clone) المستودع لن يعرف أي ملفات يجب تجاهلها.

**ارفعه مع بقية الملفات.**

## مثال على الصورة المطلوب قراءتها

لصورتك، المفترض أن يقرأ التطبيق هذه القيم بدقة:

## مفتاح Gemini API (يُنصح به لقراءة دقيقة)

عند رفع الصورة، يبحث التطبيق أولاً عن مفتاح Gemini: إن وُجد يقرأ الصورة **سحابياً بالذكاء الاصطناعي** بدقة عالية (الوقت والربح والمسافة والمدة والتاريخ). وإن لم يوجد، يعمل بمحرك محلي (Tesseract) وقد تكون القراءة أقل دقة.

احصل على مفتاح مجاني من [Google AI Studio](https://aistudio.google.com/apikey)، ثم الصقه **كاملاً** في تبويب "الإعدادات" واضغط «🔍 اختبار المفتاح» للتأكد من عمله.

- يقبل التطبيق نوعي المفاتيح: القياسي `AIza...` ومفتاح التفويض `AQ....`
- المفتاح يُخزَّن في متصفحك فقط (localStorage)، ولا يُرفع إلى GitHub، ولا يُرسل إلا لخوادم Google.
- عند استهلاك الحصة المجانية مؤقتاً، يظهر لك تنبيه وزر **"إعادة محاولة"**.
